# Отчёты агентов

Каждая задача из [`AGENT_EXECUTION_PLAN.md`](../AGENT_EXECUTION_PLAN.md) должна завершаться отчётом в этом каталоге.

Имена файлов фиксированы карточками задач:

- `T00_device_audit.md`;
- `T01_project_foundation.md`;
- `T02_dashboard_platform.md`;
- `T03_calendar.md`;
- `T04_todoist.md`;
- `T05_weather_system.md`;
- `T06_integration_ux.md`;
- `T07_meebook_eink.md`;
- `T08_reliability_security.md`;
- `T09_release_candidate.md`;
- `T10_final_review.md`.

Минимальный шаблон:

```markdown
# TXX — название задачи

## Статус
completed | blocked | completed_with_followups

## Краткий результат

## Что реализовано

## Изменённые файлы

## Принятые решения

## Проверки

## Известные ограничения

## Риски и технический долг

## Что должен знать следующий агент

## Следующая задача
```

Completion message в системе оркестрации не заменяет этот файл.
