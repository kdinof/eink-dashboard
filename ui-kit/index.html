Ink UI

Монохромный UI-кит в эстетике e-ink: белая бумага, чёрные чернила, толстые рамки и инверсия вместо цвета. Чистые CSS и vanilla JS, без сборки и зависимостей. Анимации по умолчанию выключены, чтобы экран не оставлял шлейфов.

Подключение

Один CSS-файл, одна опциональная JS-библиотека и спрайт иконок. Страница должна открываться через HTTP: из file:// спрайт не загрузится.

<link rel="stylesheet" href="ui-kit/ink.css">
<script src="ui-kit/ink.js" defer></script>

<svg class="ink-icon"><use href="ui-kit/icons.svg#i-plus"/></svg>

<!-- Своя тема: переопределите токены -->
<style>:root { --paper: #f4f1e8; --radius-sm: 0; --motion: 120ms; }</style>

Цвета

Цвета нет, есть только ступени яркости, которые не сливаются на 16-уровневом сером e-ink. Иерархию задают толщина начертания, инверсия и толщина штриха.

--ink  --ink-2  --ink-3  --ink-4  --paper  --paper-2  --paper-3  --on-ink

Отступы, штрихи, радиусы

Сетка 4px. Толстая рамка --stroke-bold — главный узнаваемый элемент стиля.

--space-1…12   --stroke-hair / --stroke / --stroke-bold / --stroke-heavy
--radius-xs / sm / md / lg / pill   --control-sm / md / lg   --motion: 0ms
