Размеры: .ink-icon--sm (14px), по умолчанию 18px, .ink-icon--lg (24px). Цвет наследуется от color. Декоративным иконкам ставьте aria-hidden="true", у кнопок-иконок — aria-label. <use href> на внешний спрайт не работает с file:// в Chrome — откройте страницу через локальный сервер или вставьте спрайт в документ.
