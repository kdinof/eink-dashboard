JavaScript

ink.js — без зависимостей, без анимаций. Подключите в конце страницы: поведение включается по data-атрибутам на DOMContentLoaded, повторная инициализация безопасна.

<script src="ink.js"></script>

<script>
  // После вставки разметки (fetch, шаблоны) — инициализировать новый фрагмент:
  InkUI.init(container);   // root по умолчанию — document
  // Уже обработанные узлы помечаются data-ink-init и пропускаются.
</script>

API

InkUI.init(root?)              // связать поведение внутри root, возвращает root
InkUI.toast(message, {duration}) // показать уведомление, duration по умолчанию 2500 мс (0 — не скрывать)
InkUI.open(idOrDialog)         // открыть <dialog> через showModal()
InkUI.close(idOrDialog)        // закрыть <dialog>

// Событие ink:change всплывает от контейнера; detail = { value, item }
el.addEventListener('ink:change', e => console.log(e.detail.value));

Чипы и сегменты

[data-ink-chips] и [data-ink-segmented]: одиночный выбор. Кнопкам с role="tab" ставится aria-selected, остальным — aria-pressed; value берётся из data-value (иначе из текста).

<div class="ink-chips" role="tablist" data-ink-chips>
  <button class="ink-chip" role="tab" aria-selected="true" data-value="all">Все</button>
  <button class="ink-chip" role="tab" aria-selected="false" data-value="news">Новости</button>
  <button class="ink-chip" role="tab" aria-selected="false" data-value="finance">Финансы</button>
</div>

<div class="ink-segmented" data-ink-segmented>
  <button class="ink-segmented__item" type="button" aria-pressed="true" data-value="day">День</button>
  <button class="ink-segmented__item" type="button" aria-pressed="false" data-value="week">Неделя</button>
</div>

<script>
  document.querySelector('[data-ink-chips]')
    .addEventListener('ink:change', e => filterCards(e.detail.value));
</script>

Вкладки

[data-ink-tabs]: кнопки с aria-controls переключают aria-selected и атрибут hidden у панелей. Клавиши ←/→ (↑/↓), Home, End перемещают выбор; активна только одна кнопка в порядке Tab (roving tabindex).

<div class="ink-tabs" role="tablist" data-ink-tabs>
  <button class="ink-tabs__tab" role="tab" aria-selected="true" aria-controls="tab-today">Сегодня</button>
  <button class="ink-tabs__tab" role="tab" aria-selected="false" aria-controls="tab-week">Неделя</button>
</div>
<div class="ink-tab-panel" role="tabpanel" id="tab-today">…</div>
<div class="ink-tab-panel" role="tabpanel" id="tab-week" hidden>…</div>

Нижняя навигация

[data-ink-tabbar]: по нажатию на ссылку или кнопку ставит ей aria-current="page", снимает с остальных и генерирует ink:change (value — data-value, иначе href).

<nav class="ink-tabbar" data-ink-tabbar>
  <a class="ink-tabbar__item" href="#todo" data-value="todo">
    <svg class="ink-icon"><use href="icons.svg#i-todo"/></svg><span class="ink-tabbar__label">Дела</span>
  </a>
  <a class="ink-tabbar__item" href="#cards" data-value="cards" aria-current="page">
    <svg class="ink-icon"><use href="icons.svg#i-cards"/></svg><span class="ink-tabbar__label">Карты</span>
  </a>
  <a class="ink-tabbar__item" href="#device" data-value="device">
    <svg class="ink-icon"><use href="icons.svg#i-device"/></svg><span class="ink-tabbar__label">Устройство</span>
  </a>
</nav>

Диалоги

[data-ink-open="id"] открывает

через showModal(). Любой [data-ink-close] внутри закрывает его (значение атрибута уходит в dialog.returnValue), клик по подложке — тоже; Esc работает нативно.

<button class="ink-button" type="button" data-ink-open="confirm-delete">Удалить</button>

<dialog class="ink-dialog" id="confirm-delete" aria-labelledby="confirm-delete-title">
  <header class="ink-dialog__header">
    <h2 class="ink-dialog__title" id="confirm-delete-title">Удалить карту?</h2>
    <button class="ink-dialog__close" type="button" data-ink-close aria-label="Закрыть">
      <svg class="ink-icon"><use href="icons.svg#i-close"/></svg>
    </button>
  </header>
  <div class="ink-dialog__body">Карта исчезнет с экрана устройства.</div>
  <footer class="ink-dialog__footer">
    <button class="ink-button ink-button--outline" type="button" data-ink-close>Отмена</button>
    <button class="ink-button" type="button" data-ink-close="ok">Удалить</button>
  </footer>
</dialog>

<script>
  document.getElementById('confirm-delete')
    .addEventListener('close', e => { if (e.target.returnValue === 'ok') removeCard(); });
</script>

Уведомление

InkUI.toast(message, {duration}) — один общий элемент .ink-toast (role="status") в body; видим при data-open="true". Повторный вызов заменяет текст и перезапускает таймер.

<button class="ink-button" type="button" onclick="InkUI.toast('Сохранено')">Показать уведомление</button>
InkUI.toast('Карта отправлена на устройство');
InkUI.toast('Нет соединения', { duration: 5000 });
InkUI.toast('Синхронизация…', { duration: 0 }); // висит до следующего вызова

Степпер

[data-ink-stepper]: кнопки [data-ink-step="-1"] и [data-ink-step="1"] меняют input[type=number] на step, соблюдая min/max; на границе кнопка получает disabled. На input генерируются input и change, на контейнере — ink:change.

<div class="ink-stepper" data-ink-stepper>
  <button class="ink-stepper__btn" type="button" data-ink-step="-1" aria-label="Меньше">
    <svg class="ink-icon"><use href="icons.svg#i-minus"/></svg>
  </button>
  <input class="ink-stepper__value" type="number" value="15" min="5" max="60" step="5" aria-label="Интервал, мин">
  <button class="ink-stepper__btn" type="button" data-ink-step="1" aria-label="Больше">
    <svg class="ink-icon"><use href="icons.svg#i-plus"/></svg>
  </button>
</div>

Часы

[data-ink-clock] выводит HH:MM (24 ч) и обновляется ровно на границе минуты — без посекундных перерисовок. data-format="date" даёт дату через Intl ru-RU: «26 сентября, сб». Текст меняется только при реальном изменении; у обновляется datetime.

<time class="ink-num" data-ink-clock>17:18</time>
<span class="ink-caption" data-ink-clock data-format="date"></span>
